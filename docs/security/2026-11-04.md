## 1) 오늘의 결론
1. High 없음. 가장 큰 위험은 **CDN에서 받는 JS(mediabunny 등)에 무결성 검증·CSP가 없다**는 점(F-01/F-02). 악성 JS가 실행되면 로컬 영상을 외부로 보낼 수 있어 "업로드 없음" 약속이 깨질 수 있음.

CSP 스니펫(예시, 벤더링 후 기준):
```html
<meta http-equiv="Content-Security-Policy" content="default-src 'none'; script-src 'self' 'unsafe-inline' 'wasm-unsafe-eval' blob:; style-src 'self' 'unsafe-inline'; img-src 'self' blob: data:; media-src blob:; worker-src blob:; connect-src 'self' blob:; base-uri 'none'; form-action 'none'">
<meta name="referrer" content="no-referrer">
```
(현재 CDN 구성에서는 `script-src`·`connect-src`에 `https://cdn.jsdelivr.net`, 폰트에 `fonts.googleapis.com fonts.gstatic.com` 추가 필요.) 적용 전 실제 동작 테스트 필요(미검증).

## 3) 외부 동향
- **mediabunny**: npm 최신 1.65.1(2026-11-03), 현재 사용 1.61.4. 1.64.0 노트: TrueHD 지원, Opus pre-roll 400ms, Android Chrome 오래된 VideoFrame 우회 ([Dependabot PR 인용](https://github.com/damiarita/slingsite/pull/54), [npm registry](https://registry.npmjs.org/mediabunny)). 1.62/1.63/1.65 변경점은 미확인 → [릴리스 페이지](https://github.com/Vanilagy/mediabunny/releases) 확인 필요. 보안 수정은 확인되지 않음. **권장: 비긴급, 1.65.x로 올려 회귀 테스트 후 반영** (prores도 1.65.1 동일 버전, 세트로 올릴 것).
- **@suemor/libav-hevc**: 0.1.1이 최신(2026-09-06 이후 변경 없음, [npm](https://registry.npmjs.org/@suemor/libav-hevc)). 신규 릴리스 없음.
- **FFmpeg CVE**: HEVC 디코더 자체의 2026 CVE는 검색에서 확인되지 못함. CVE-2026-75141은 hvcC **muxer** 힙 오버플로([SentinelOne](https://www.sentinelone.com/vulnerability-database/cve-2026-75141/)) — 본 앱은 디코더 전용 빌드라 영향 낮을 것으로 보이나 미확인. 그 외 CVE-2026-8461(MagicYUV 디코더, [Penligent](https://www.penligent.ai/hackinglabs/pixelsmash-cve-2026-8461/))은 HEVC 무관. libav 번들의 FFmpeg 버전(6.x 계열로 추정, 파일명 `libav-6.10.9.0`)은 최신보다 오래되어 향후 디코더 CVE에 노출 가능.
- **Chrome**: 10/27 Chrome 156.0.8078.73에서 Media 메모리 손상 2건(CVE-2026-118327, -118311)과 Video 1건 수정 보도 ([CyberSecurityNews](https://cybersecuritynews.com/google-fixes-52-chrome-security-flaws/), 2차 출처, 공식 Chrome Releases로 재확인 필요). WebCodecs 전용 공지는 확인 못 함. 사용자에게 브라우저 최신 유지 안내 권장.
- 출처 간 날짜·버전 불일치가 있어 Chrome 항목은 낮은 신뢰도.

## 4) 더 공부할 것
1. **WebCodecs + HDR/색공간 메타데이터(VideoColorSpace, BT.2020/PQ/HLG) 처리** — 아이폰·AI 영상의 10비트/HDR 입력에서 색보정 기준이 어긋나지 않게. [WebCodecs 사양](https://www.w3.org/TR/webcodecs/), [MDN VideoColorSpace](https://developer.mozilla.org/en-US/docs/Web/API/VideoColorSpace)

3. **Subresource Integrity와 importmap integrity 브라우저 지원** — F-01 대안 검증. [MDN SRI](https://developer.mozilla.org/en-US/docs/Web/Security/Subresource_Integrity)
