## 1) 오늘의 결론
1. **새 항목 F-09 (Med)**: 사용 중인 mediabunny 1.61.4에는 1.62.0의 악성 입력 강화 패치가 빠져 있습니다. 메모리·CPU 고갈, 무한루프, 스택 오버플로, ProRes 범위 밖 읽기 등이 해당합니다. 1.65.2로 올리는 것을 권장합니다. 올릴 때 importmap의 integrity 해시도 같이 바꿔야 합니다.
2. main에는 변경이 없습니다. 어제 고친 F-01·F-02·F-06과 F-05 일부는 `ccr-7f9d7924-5dyc1m` 브랜치에만 있어 **배포된 사이트는 아직 그대로**입니다.
3. FFmpeg HEVC 취약점 CVE-2026-64831(High)은 Vulkan 하드웨어 디코더 경로이고 영향 버전은 FFmpeg 8.x입니다. 이 앱이 쓰는 libav.js WASM 빌드(6.x, 소프트웨어 디코더)는 해당하지 않을 것으로 봅니다(빌드 구성은 직접 확인하지 못해 미확인).

## 3) 외부 동향
- **mediabunny / @mediabunny/prores 1.65.2** 출시(npm 기준 2026-11-04). 1.65.2 자체는 fMP4 키프레임 처리, AES 설명 스트림 오류, sparse 키프레임 탐색 성능 수정입니다. 보안상 중요한 것은 1.62.0입니다(위 F-09). 출처: [Releases](https://github.com/Vanilagy/mediabunny/releases), [npm](https://registry.npmjs.org/mediabunny). 릴리스 페이지 요약에 표시된 연도와 npm 날짜가 달랐는데, 날짜는 npm 기준으로 적었습니다.
- **@suemor/libav-hevc**: 0.1.1 그대로입니다(npm 마지막 변경 2026-09-06).
- **FFmpeg CVE-2026-64831**: Vulkan HEVC 디코더(`vk_hevc_end_frame`)의 스택 오버플로이고 영향 버전은 8.0~8.1.2입니다. 출처: [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-64831), [SentinelOne](https://www.sentinelone.com/vulnerability-database/cve-2026-64831/). 이 앱에는 해당하지 않을 것으로 봅니다(미확인. libav 6.x 계열이고 WASM 빌드에는 Vulkan이 없음).
- **Chrome**: 11월 Stable 보안 업데이트는 확인하지 못했습니다(미확인). 공식 목록은 [Chrome Releases](https://chromereleases.googleblog.com/)에서 확인할 수 있습니다.

## 4) 더 공부할 것
1. **Worker + OffscreenCanvas로 디코딩 분리**: F-05에 남은 문제(HEVC WASM이 메인 스레드에서 돌아 탭이 멈출 수 있음)를 해결하는 방법입니다. 멈춘 Worker는 `terminate()`로 강제 종료할 수 있습니다. [MDN OffscreenCanvas](https://developer.mozilla.org/en-US/docs/Web/API/OffscreenCanvas), [MDN Worker.terminate](https://developer.mozilla.org/en-US/docs/Web/API/Worker/terminate)
2. **해시 기반 strict CSP와 Trusted Types**: 지금 CSP에 남아 있는 `'unsafe-inline'`을 없애는 방법입니다. 인라인 스크립트의 해시를 `script-src`에 넣는 방식입니다. [web.dev Strict CSP](https://web.dev/articles/strict-csp), [MDN Trusted Types](https://developer.mozilla.org/en-US/docs/Web/API/Trusted_Types_API)
3. **3D LUT 보간 방식(trilinear vs tetrahedral)**: 33³ LUT를 적용할 때 채도가 높은 영역의 정확도에 영향을 줍니다. 검색어: "tetrahedral interpolation 3D LUT GPU shader"
