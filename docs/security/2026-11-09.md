# 보안·기술 리포트 2026-11-09

## 1) 오늘의 결론
1. main과 의존성에는 변화가 없습니다. PR #1은 아직 머지되지 않았습니다.
2. **새 항목 F-11 (Low)**: libav-hevc 0.1.1에 들어 있는 FFmpeg(6.x 계열 추정)는 2026-09 이후 갱신되지 않았습니다. 그 사이 FFmpeg 취약점이 대량으로 공개됐고, AI 분석으로 찾은 21건 등이 보도됐습니다. 이 앱의 HEVC 디코딩 경로가 영향을 받는지는 미확인입니다.
3. 영향은 WASM 샌드박스 안에서 일어나는 메모리 손상(탭 오류·멈춤)으로 한정됩니다. 브라우저 밖으로 번지지는 않습니다. 지금 할 일은 상위 저장소 갱신을 지켜보는 것입니다.
