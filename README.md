# FinishRoom 종편실

Make every clip look like your reference — automatic color matching in the browser. Nothing to install, and your videos never leave your computer.

**Open the app:** https://totaldc200-lab.github.io/finishroom/

1. Add a reference video or screenshots (the look you want)
2. Add the videos to correct
3. Set the strength and save

Works in Chrome, Edge and Safari. Reads MP4/MOV incl. ProRes and 10-bit HEVC.
